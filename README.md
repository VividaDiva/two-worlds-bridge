# Two Worlds, One Bridge

Four browser simulations on what happens to people when an AI mediates between them.

**Live:** https://vividadiva.github.io/two-worlds-bridge/

Two people describe the same place in ways that cannot both be true. An AI in the
middle has to build something anyway. Each piece is a working instrument rather than
a mockup — everything runs client-side, with no build step, no dependencies and no
account.

| | |
|---|---|
| [Two Worlds, One Bridge](two-worlds-bridge.html) | One role sees a river between two cities, the other a mountain between two villages. The same gap, described incompatibly, and one structure that must stand in both. Includes an idea-space view showing every word said against the few the world picked up. |
| [I Want, I Do Not Want](i-want-i-do-not-want.html) | Both people are simulated. One may only say "I want…", the other only "I do not want…". The machine builds in matchsticks. Three cases: as given, voices swapped, and each participant alone with the machine. |
| [Five Fairnesses](five-fairnesses.html) | The same brief solved five times under five definitions of fairness — utilitarian, Rawlsian, Nash, precautionary, whoever-pays. Each builds a different bridge; one builds nothing. |
| [Toolmakers Protocol](toolmakers-protocol.html) | A session runner for studying this with real participants: printable private briefs, an operator console, separate debriefs, and a comparison of what each person left believing had been built. |

## Background

The premise comes from Michael Reddy's 1979 essay *The Conduit Metaphor*, which argues
that English talks about communication as if ideas were objects placed in words and
sent along a conduit — and that this is false. Meaning is rebuilt by the receiver out
of whatever their own environment contains. Reddy's alternative, the "toolmakers
paradigm", describes people in separate environments exchanging crude blueprints and
building different things from them without ever finding out.

## Running locally

Open any `.html` file directly in a browser. There is nothing to install.
