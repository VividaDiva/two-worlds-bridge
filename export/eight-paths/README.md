# Eight paths — bridges and chats

160 machine sessions on the same eight communication paths as the live user test (5 scenarios × 4 persona pairs per path).
Role 1 = gpt-4o, Role 2 = claude-opus-5, builder = gemini-flash-lite. Bridges drawn with the live experiment's draw.js.

- `bridges/<path>/<scenario>-pair<n>.jpg` — one picture per session, grouped by communication path
- `bridges-by-shape/<bridge name>/` — the same pictures grouped by what was built
- `chats/<path>/<scenario>-pair<n>.md` — full transcript, cast, hidden needs (✓/✗), what was built
